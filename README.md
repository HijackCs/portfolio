# Portfolio — Hugo Schroder

Personal portfolio of Hugo Schroder, software engineer. A static, prerendered website
showcasing projects across mobile apps, web & SaaS, IoT and tooling.

Built with **Nuxt 4**, **Vue 3**, **Tailwind CSS v4** and **GSAP** for animations.

## Tech stack

- [Nuxt 4](https://nuxt.com/) — Vue framework, fully prerendered (static generation)
- [Vue 3](https://vuejs.org/) + [Vue Router](https://router.vuejs.org/)
- [Tailwind CSS v4](https://tailwindcss.com/) via the `@tailwindcss/vite` plugin
- [GSAP](https://gsap.com/) — scroll and entrance animations (`app/composables/useGsap.ts`)
- [`@nuxt/image`](https://image.nuxt.com/) — optimized images
- [`@nuxt/fonts`](https://fonts.nuxt.com/) — Space Grotesk, Inter, JetBrains Mono
- [`@nuxt/eslint`](https://eslint.nuxt.com/) — linting with stylistic rules
- TypeScript

## Project structure

```
app/
├── app.vue                 # Root layout (NavBar, page, Footer, custom cursor)
├── assets/css/main.css     # Tailwind entry + global styles
├── components/
│   ├── home/               # Landing sections (Hero, Pillars, FeaturedProjects, AboutTeaser)
│   ├── projects/           # ProjectCard, ProjectFilter, ProjectMedia, ProjectLightbox
│   └── shared/             # NavBar, Footer, CustomCursor, GradientText
├── composables/
│   └── useGsap.ts          # GSAP helpers
├── data/
│   └── projects.ts         # Single source of truth for all project content
└── pages/
    ├── index.vue           # Home
    ├── about.vue           # About
    ├── contact.vue         # Contact
    ├── mentions-legales.vue # Legal notice
    └── projects/
        ├── index.vue       # Projects listing (filterable)
        └── [slug].vue      # Project detail page

public/
└── projects/<slug>/        # Screenshots referenced from app/data/projects.ts
```

### Adding or editing a project

All project content lives in [`app/data/projects.ts`](app/data/projects.ts). Add an entry to
the `projects` array following the `Project` interface, set `featured: true` to surface it on
the home page, and drop the matching screenshots under `public/projects/<slug>/`. Detail pages
are generated automatically at `/projects/<slug>` thanks to Nitro link crawling.

## Setup

Install dependencies:

```bash
npm install
```

## Development

Start the dev server on `http://localhost:3000`:

```bash
npm run dev
```

## Production

The site is fully prerendered (static). Generate the static output:

```bash
npm run generate
```

Or build and preview a production server:

```bash
npm run build
npm run preview
```

Routes (`/`, `/projects`, `/about`, `/contact`, `/mentions-legales`) are prerendered, and
each `/projects/<slug>` page is generated by crawling links from the prerendered pages
(see `nuxt.config.ts`).
